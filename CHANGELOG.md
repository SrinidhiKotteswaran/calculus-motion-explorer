# Changelog

## 1.0.0 — Motion Explorer

First stable milestone for the rebuilt web application.

### Core

- Custom expression tokenizer and recursive-descent parser
- AST-based numerical evaluation
- Symbolic differentiation and simplification
- Position, velocity, acceleration, and higher-derivative visualization

### Numerical laboratories

- Forward, backward, and central finite differences
- Step-size/error investigation
- Secant-to-tangent convergence visualization
- Root and critical-point analysis
- Increasing/decreasing and concavity analysis
- Riemann-sum and numerical integration experiments
- Procedurally generated calculus challenges

### Engineering

- Domain-aware handling of non-finite numerical results
- Root-finding and analysis edge-case hardening
- Repeatable math-engine verification suite
- Repeatable math-engine benchmark
- Technical architecture and limitations documentation
